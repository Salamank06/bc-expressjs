# Ejercicio 02 — Patrones asíncronos (Constructora)

Compara los tres patrones asíncronos de Node.js (callbacks, promesas, async/await) aplicados a la consulta de **materiales de construcción**.

## Cómo correrlo

```bash
cd bootcamp/week-01-nodejs_fundamentals/2-practicas/ejercicio-02-async/starter
npm install
npm run dev
```

## Archivos

- `src/index.ts` — ejecuta los tres ejemplos en serie
- `src/01-callbacks.ts` — versión con callbacks
- `src/02-promises.ts` — versión con Promesas
- `src/03-async.ts` — versión con async/await
- `src/types.ts` — tipos del dominio
- `data/materiales.json` — dataset de seed
